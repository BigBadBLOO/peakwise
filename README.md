# Peakwise

Модульное приложение для обучения.

## [⬇️ Скачать последний APK](https://github.com/BigBadBLOO/peakwise/releases/latest)

> Нажми на ссылку выше → найди файл `.apk` в Assets → скачай и установи  
> На Android: разреши установку из неизвестных источников

---

## Модули

- **✍️ Изложение и сочинение** — ИИ генерирует текст, пользователь пишет изложение и сочинение, ИИ проверяет и даёт обратную связь
- **🃏 Карточки** — заучивание по методу интервальных повторений (SM-2). Поддержка цепочек карточек (для стихов и последовательностей)

## Настройки

- Claude по подписке — через мост к Claude Code на компьютере (адрес и токен моста, токен хранится в secure storage)
- Порядок вкладок и их видимость

## ИИ по подписке Claude

Приложение не ходит в Anthropic API напрямую. Запросы идут на маленький мост на твоём Mac,
который запускает Claude Code (`claude -p`) — так же, как это делает [amanu](https://github.com/gsamat/amanu).
Тратится подписка claude.ai, API-ключ не нужен.

1. На Mac должен быть установлен и залогинен Claude Code (`claude` → `/login`).
2. Запусти мост: `npm run bridge` — он напечатает адреса и токен.
3. В приложении: Настройки → AI Provider → адрес (например `http://192.168.1.10:8787`) и токен.
   Статус «работает» означает, что мост отвечает и Claude Code вошёл по подписке; иначе там будет текст ошибки.

Телефон и Mac должны быть в одной сети. Вне дома можно использовать [Tailscale](https://tailscale.com) и адрес Mac в tailnet.

## Сборка

```bash
npm install
npm run android  # запустить на эмуляторе/устройстве
```

APK автоматически собирается при каждом пуше в `main`.

# Skill: workout-program

Анализирует экспортированные данные тренировок и генерирует новую программу.

## Когда использовать

Пользователь прикрепил файл `peakwise_workouts.json` (экспорт из приложения) и хочет получить новую программу тренировок.

## Инструкция

1. Прочитай прикреплённый файл экспорта (`peakwise_workouts.json` или аналогичный).
2. Проанализируй:
   - Текущие программы (структура, упражнения, целевые веса/повторения)
   - Историю сессий последних 30 тренировок:
     - Прогрессия весов по каждому упражнению
     - Ощущение от подходов (1=Легко, 2=Нормально, 3=Тяжело)
     - Частота тренировок
3. Сформулируй рекомендации: какие веса повысить, какие упражнения добавить/убрать, нужна ли смена программы.
4. Сгенерируй новую программу **строго в формате JSON ниже** — без лишнего текста вокруг JSON блока.

## Выходной формат (ImportProgram)

```json
{
  "name": "Название программы",
  "description": "Краткое описание цели",
  "days": [
    {
      "name": "День А — Грудь/Плечи/Трицепс",
      "exercises": [
        {
          "name": "Жим штанги лёжа",
          "rest_seconds": 120,
          "sets": [
            { "set_number": 1, "target_reps": 5, "target_weight": 80 },
            { "set_number": 2, "target_reps": 5, "target_weight": 80 },
            { "set_number": 3, "target_reps": 5, "target_weight": 80 }
          ]
        }
      ]
    }
  ]
}
```

**Правила:**
- `rest_seconds` по умолчанию 90 для изоляции, 120-180 для базовых
- `target_weight` в кг, `null` если вес телесный или неизвестен
- `target_reps` количество повторений, `null` для упражнений на время
- Прогрессия: если последние 2-3 сессии ощущение "Легко" (feeling=1) — повысь вес на 2.5-5 кг; если "Тяжело" (feeling=3) — оставь или снизь

После JSON блока коротко (2-3 предложения) объясни ключевые изменения относительно текущей программы.
